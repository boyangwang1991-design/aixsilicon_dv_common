# DPI 目录（严格受限）

DPI 仅用于文件、压缩、性能敏感模型、外部模型桥接等必要场景。

## 约束

1. 每个 DPI 组件必须：
   - 有纯 SV fallback 或明确声明不支持；
   - 声明平台、编译器、仿真器矩阵；
   - 不让公共核心组件依赖 DPI；
   - 单独 Core 发布；
   - 具备内存/线程安全检查。
2. 禁止在 L0/L1 公共核心中引入 DPI。

## 结构

```text
dpi/
├── include/   # 共享头文件（类型、宏）
├── src/       # DPI 源文件（C/C++），当前为空骨架
└── README.md
```

## 当前状态

- 一期骨架：仅定义共享类型头 `include/dv_dpi_types.svh`，无实际 DPI 组件。
- 后续 DPI 组件须按上述约束单独 Core 发布并填写 `src/` 与平台矩阵。
